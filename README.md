# printess-skills
A collection of skills for AI tools to work with Printess.

These skills should enable you to fully integrate the Printess Editor into your website, including the production of output files.

You can also create custom dialogs in the editor through scripting.

The `/dist` directory contains all skills accompanied by the additional resources for each skill.

If you want to use any one skill, you can download its directory in the `/dist` folder.
